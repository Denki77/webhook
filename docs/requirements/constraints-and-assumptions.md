# Constraints and Assumptions

Технические, организационные и инфраструктурные ограничения и допущения.

## Назначение документа

Этот документ описывает ограничения и допущения для Webhook Delivery Service.

## Безопасность

### CON-001. Доверенная внутренняя сеть

В первой версии сервис доступен только доверенным внутренним системам внутри закрытого инфраструктурного контура.

### CON-002. Аутентификация

Сервис не реализует самостоятельную аутентификацию вызывающей стороны.

### CON-003. Идентификация

Идентификация и ограничение доступа обеспечиваются внешним инфраструктурным контуром.
