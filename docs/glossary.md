# Glossary

**Клиент** — сторона, которой принадлежит интеграция.

**Endpoint** — технический адрес доставки, указываемый клиентом.

**Recipient** — система, фактически принимающая запрос.

**Subscription** — согласие и настройки получения типа события.

**Event** — бизнес-факт.

**Доставка событий** — набор действий по доставке события до клиента от момента уведомления сервисом статуса принятия события.

**Delivery attempt** — одна попытка передачи.

**Протокол согласования события** - зафиксированный документом формат сообщения, не подлежащий изменению в
зафиксированной версии.

**Принятое событие** — событие, за дальнейшую обработку которого сервис принял ответственность.

**Подтверждение принятия** — ответ сервиса источнику события, свидетельствующий о принятии такой ответственности.

**Отказ в принятии** — ответ сервиса, означающий, что ответственность за дальнейшую обработку события сервисом не
принята.

**Принятый интервал** — интервал времени, в течение которого сервис подтверждает принятие ответственности за дальнейшую
обработку события или отказ в принятии.

**Успешная передача события** — получение от получателя подтверждения, которое, согласно версии интеграционного
контракта, означает принятие уведомления.
Для HTTP-интеграции по умолчанию таким подтверждением является ответ с кодом `2xx`, если контрактом не определено иное.
